🔑 Доступ

Токен хранится только в этом браузере и никуда, кроме GitHub, не отправляется.
Где взять токен?
  1. Зайди на GitHub под аккаунтом, у которого есть доступ к репозиторию SOLYNE-1/pinkykei.
  2. Открой Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → выбери pinkykei.
  4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.
  5. Срок действия поставь максимальный, создай токен и вставь его сюда.
